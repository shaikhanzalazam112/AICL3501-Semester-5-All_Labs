# Lab 3: Implementation of Activation Functions

## Objective
To implement and compare Sigmoid, Tanh, ReLU, and Leaky ReLU activation functions using PyTorch.

## Tools
- Google Colab
- Python
- PyTorch
- Scikit-learn
- Iris Dataset

## Lab Tasks
- Implement Sigmoid, Tanh and ReLU.
- Add Leaky ReLU.
- Compare activation function plots.
- Build models using different activation functions.
- Compare raw outputs using 5 Iris samples.
