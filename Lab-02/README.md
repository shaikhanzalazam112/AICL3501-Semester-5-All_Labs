# ANN Lab 02 – Perceptron From Scratch

This lab introduces the Perceptron, the simplest artificial neuron model.

## Objectives
- Understand the working of a perceptron.
- Implement a perceptron from scratch using Python and NumPy.
- Train the perceptron on the AND gate.
- Test the perceptron on the XOR gate.
- Understand why a single perceptron cannot solve XOR.
- Understand the concept of linear separability.

## Tools
- Google Colab
- Python
- NumPy

## Tasks
1. Implement a perceptron from scratch.
2. Train the perceptron on the AND gate.
3. Test the trained perceptron.
4. Visualize the AND gate data.
5. Train the perceptron on the XOR gate.
6. Analyze why the perceptron fails on XOR.
