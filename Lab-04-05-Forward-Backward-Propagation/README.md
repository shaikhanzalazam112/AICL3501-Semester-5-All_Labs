# Lab 4 & 5: Forward and Backward Propagation in Neural Network

## Objective
To understand forward propagation and backpropagation and train a simple feedforward neural network using PyTorch.

## Dataset
MNIST handwritten digit dataset.

- Training images: 60,000
- Test images: 10,000
- Image size: 28 × 28
- Classes: 10

## Tools
- Python
- PyTorch
- torchvision
- Matplotlib
- Google Colab

## Main Concepts
- Forward Propagation
- Cross-Entropy Loss
- Backpropagation
- Gradient Descent
- Adam Optimizer
- Epochs and Batches
- Model Evaluation

## Lab Tasks
1. Change hidden neurons from 128 to 32 and 256.
2. Increase epochs from 3 to 10.
3. Replace ReLU with Sigmoid and Tanh.
4. Replace Adam with SGD.
5. Add a second hidden layer.

## Submission
Completed Google Colab notebook with executed code, outputs, and analysis.
